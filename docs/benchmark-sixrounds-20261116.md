# 六轮单网/双网对照（2026-11-16）

F50、同一清华镜像文件、4 条并发 HTTPS Range 下载，单项合计约 15.5 MiB。六轮交替顺序：单网→双网、双网→单网。临时核心由插件现行 boost.rb 生成域名子规则，设备为 all，round-robin。基线强制 Wi-Fi；加速使用双出口组。记录连接 chains，强制校验基线只走 Wi-Fi，双网必须同时观察到 Wi-Fi 和移动节点。含建连、TLS 和总完成时间，非单连接叠加测速。

| 轮次 | Wi-Fi Mbps | 双网 Mbps |
|---|---:|---:|
| 1 | 93.67 | 30.21 |
| 2 | 65.30 | 153.10 |
| 3 | 56.00 | 137.07 |
| 4 | 77.06 | 123.35 |
| 5 | 46.49 | 122.90 |
| 6 | 86.33 | 112.08 |

合并全部成功下载字节／总完成时间：Wi-Fi 66.73 Mbps、双网 83.22 Mbps，提升 24.7%。六轮有五轮双网更快，一轮明显更慢；不保证始终比 Wi-Fi 快。48 条正式测试连接全部 HTTP 206 成功完成。结果仅适用于此时、此域名及短连接组合，不代表所有游戏 CDN 或长期速率。

最初一批测试的临时进程名也是 clash，被生产插件误识别并覆盖了域名选择器，部分基线实际走双网，因此该批数据全部废弃。正式重测使用独立进程名 wds-bench-core，避免 pidof clash 选中临时实例，并对每轮 chains 做断言。正式测试结束后临时核心退出，生产实际配置确认 round-robin。

有效测试加废弃测试，接口接收统计合计移动数据约 130.7 MiB（含同期后台流量，不是运营商账单）。未更改生产加速范围、开关和额度，仅将移除的稳定优先迁移到轮流分配。
